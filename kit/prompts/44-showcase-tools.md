# Prompt 44 of 46 (v0.5): showcase tools (seeds, replays, showcase mode, clip capture)

Follow AGENTS.md. Goal: make it easy to share the game: shareable worlds, replays and ready-to-publish clips. First read core/game.py, core/save.py, scripting/manager.py, ui/app.py, tools/screenshot.py, audio/manager.py and ui/fx/*.

1. Seeds: 'New game...' in the File menu with a seed field (a random button and a copy button); the CLI flag --seed N; the current seed is shown in About and in the tooltip of the HUD.
2. Replay files (.msreplay, a zip with JSON): the seed, the game version, a snapshot of the save at the start, the scripts, which miner runs which script from which tick, and the number of ticks. 'Export replay...' in the File menu (it asks for the duration) and `minesim --replay file [--ticks N]`, which loads it and plays it in lockstep (a 'Replay' banner, scripts read-only). Manual UI actions are not part of replays. Playing the same file twice is deterministic.
3. Showcase mode (key F9 and the View menu): hides the HUD, menus and panels; presets for a 1080x1920 (9:16) and a 1920x1080 window; a gentle cinematic camera (slow follow and a very small zoom breathing; off with reduce motion); photo mode (pause and a free camera). F12 saves a PNG to the Pictures folder (platformdirs) with a toast; Ctrl+F12 saves it with the UI hidden.
4. tools/capture_clip.py: `--replay file --seconds 20 --size 1080x1920 --fps 30 --speed 5 --out clip.mp4 [--gif] [--no-audio]`. It runs offscreen and headless in lockstep with a fixed time step, renders the showcase view of every frame, pipes raw frames to ffmpeg (libx264, yuv420p) and, unless --no-audio, mixes an audio track offline: the SFX that the AudioManager logged with their timestamps plus the music loop of the viewed layer, using the cached synthesized buffers, then muxes it. Effects and audio use the deterministic seeds, so the same replay gives the same clip. It fails with a clear message when ffmpeg is missing.
5. docs/SHOWCASE.md: how to capture clips from a replay on a server without a screen, how to share seeds, and a checklist for a good 20-second clip (a hook in the first two seconds, one clear idea, readable code on screen).
6. Tests: replay export and import round trip; two replay runs give identical engine states; showcase mode hides the UI and F12 writes a PNG (offscreen); capture_clip with a tiny replay: with ffmpeg available it produces a 1-second clip whose duration ffprobe reports correctly (skip the test when ffmpeg is missing) and the frame hashes of two runs match; the offline audio mix has the same length as the video.

ACCEPTANCE: a 20-second vertical clip with sound can be produced from a replay with one command.
