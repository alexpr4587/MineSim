# Balance report

Generated by `tools/balance_sim.py` from a headless 400,000-tick simulation of four strategies on seed 12345. This is a report only; no gameplay numbers were tuned.

- **Random walker**: walks randomly, mines any unlocked ore it can and sells only when it happens to stand on the base.
- **Serpentine sweeper**: follows an outward serpentine path, returns home to sell when the inventory is full and buys the cheapest available upgrade level before resuming.
- **Warehouse trader**: mines and unloads into the warehouse, sells stock only when the market index is at least 1.1, refines every unlocked recipe it can, delivers contracts, buys upgrades and spawns a second miner. Both miners run in lockstep.
- **Deep fleet**: keeps the warehouse trader economy, expands to five miners, buys the shaft and climate upgrades, sends miners to layer quotas, charges and cools at stations, and deliberately lets one miner overheat and run dry.
