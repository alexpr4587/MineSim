# Balance report

Generated by `tools/balance_sim.py` from a headless 200,000-tick simulation of two simple strategies on seed 12345. This is a report only; no gameplay numbers were tuned.

- **Random walker**: walks randomly, mines any unlocked ore it can and sells only when it happens to stand on the base.
- **Serpentine sweeper**: follows an outward serpentine path, returns home to sell when the inventory is full and buys the cheapest available upgrade level before resuming.
